# Methodology
AI is a powerful tool but depending on it is a nasty crutch. I am using AI as a tool.
My projects are done in 3 simple steps in order for me to lock it in:

1. Do the project with AI set strictly as a tutor, never giving me direct answers and quizzing me on what to do next, while I take detailed notes
2. Do the lab once more with just my notes and nothing else
3. Do the lab strictly using memory

Only then will they be uploaded on GitHub and posted on LinkedIn.
